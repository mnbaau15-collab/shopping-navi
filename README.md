# かんたん お買い物ナビ

高齢者が、近くのお店を簡単に探して、チラシを確認し、お店までの行き方を調べられる、買い物の手助けのWebアプリです。山形県の庄内地域（酒田市・三川町・庄内町・遊佐町）の、スーパーなど22軒に対応しています。

## 公開URL

https://mnbaau15-collab.github.io/shopping-navi/

スマホのブラウザで開いてください。ダウンロードや登録は、いりません。

## 作った理由

- 親が、スマホで「近くのお店」「今週のチラシ」「行き方」を調べるのに、迷ってしまう。
- 文字が小さい、ボタンが押しにくい、言葉が難しい、という声がある。
- 「迷わない・読める・押しやすい」を、いちばんの目標にしました。

## 使い方

表紙に、3つの探し方のカードがあります。

| カード | できること |
|---|---|
| 現在地から さがす（緑） | いまいる場所から近い順に、お店を出す |
| 市や町から さがす（オレンジ） | 4つの市や町から選んで、あいうえお順に出す |
| お店の 名前で さがす（青） | 名前の最初の文字を入れると、候補が出る |

お店のカードには、3つのボタンがあります。

1. **チラシを さがす**：そのお店のトクバイのページが、新しいタブで開く。
2. **お店の ページを 見る**：お店の公式ページが、新しいタブで開く。
3. **行き方を 調べる**：Googleマップで、お店までの道すじが開く。

## 成果物の確認方法

1. 上の公開URLを、スマホで開く。
2. 「お店の 名前で さがす」に「まっくす」と入れて、候補が出ることを見る。
3. 「市や町から さがす」で「酒田市」を選んで、あいうえお順に13軒出ることを見る。
4. 「現在地から さがす」を押して、位置情報を許可すると、近い順にお店が出ることを見る。
5. お店のカードの3つのボタンを押して、それぞれのページが新しいタブで開くことを見る。

## 高齢者向けの工夫

- 文字の基準は28px（大きめ）。ボタンは、60px以上の高さで、絵と文字をいっしょに出す。
- 難しい言葉をさけ、「探す」は、ひらがなの「さがす」にそろえる。
- 文の区切り（文節）で、改行する。
- 探し方ごとに、緑・オレンジ・青の色を変えて、いまどこにいるか分かるようにする。
- 現在地が使えないときも、「市や町」「お店の名前」で探せる。
- 位置情報は、距離の計算だけに使う。**外に送らず、保存もしません。**

## 使っている技術

- HTML・CSS・素のJavaScript（フレームワークなし、ビルドなし。ファイルを置くだけで動く）
- お店のデータは、`data/stores.js` に書いた配列（サーバーもデータベースもなし）
- 公開は GitHub Pages
- 開発には Claude Code を活用

## 店舗データの更新の仕組み

お店の住所・電話番号・営業時間は、変わることがあります。そこで、**月に1回、自動で「更新案」を作る**仕組みを作りました。

1. 毎月1日に、GitHub Actions が動く（`.github/workflows/update-stores.yml`）。
2. お店の**公式ページだけ**を、1軒1回、3秒おきに読む（相手のサーバーに、負担をかけないため）。
3. Claude（Anthropic API）が、住所・電話番号・営業時間を取り出す。
4. 変わっていた分を、**プルリクエスト**にして、持ち主へメールで知らせる。
5. **人が公式ページと見比べて「Merge」を押したときだけ**、データに反映される。

自動で書き換えることは、していません。かならず人が確認します。

### 守っていること

- トクバイには、プログラムでアクセスしません（利用規約と `robots.txt` で、禁止されているため）。
- チラシの画像や内容を、保存したり、転載したりしません。リンクだけを張ります。
- チラシのリンクは、人が開いて確認してから登録します。

## 動かし方（パソコン）

```
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。現在地は、HTTPSまたは localhost でだけ使えます。

### 検査

```
node tools/check-stores.js   # お店のデータの形を検査する
node tools/test-app.js       # 画面の動きの自動テスト
```

## フォルダ

| 場所 | 内容 |
|---|---|
| `index.html` `css/` `js/` `data/` `images/` | アプリ本体 |
| `tools/` | データの検査・自動テスト・月1回の更新案づくり |
| `.github/workflows/` | GitHub Actions の設定 |
| `verify/` | 課題用の検証（アプリには組み込まない） |
| `docs/` | 説明メモ（`explanation.md`、`auto-update-feasibility.md`） |
| `CLAUDE.md` | 開発方針 |

`verify/route-check.html` を動かすには、`verify/config.example.js` を `verify/config.js` にコピーして、自分のAPIキーを書いてください。`config.js` は `.gitignore` に入っていて、GitHubには上がりません。

## 注意

- 対応しているのは、庄内地域の4つの市や町のお店だけです（鶴岡市は、対象外です）。
